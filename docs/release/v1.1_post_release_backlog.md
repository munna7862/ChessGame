# ChessForge v1.1 Post-Release Engineering Backlog

**Document Version:** `1.1.0-PLAN`  
**Status:** Approved Post-Release Backlog  
**Baseline Release:** ChessForge v1.0.0 (`v1.0.0`)  
**Scope Freeze Policy:** Strictly isolated from v1.0.0 production code.

---

## 1. Executive Summary

This backlog captures approved feature candidates, performance optimizations, and architectural enhancements for the upcoming **ChessForge v1.1** development cycle. All items listed here are explicitly excluded from the v1.0.0 release candidate to preserve release stability and prevent scope creep.

---

## 2. Prioritized Feature Backlog

### 2.1 Domain & Chess Rules Enhancements

- **BL-1101: Chess960 (Fischer Random Chess) Engine & Setup:**
  - Support for 960 starting positions via standard FEN / X-FEN notation.
  - Castling rule adaptations for Chess960 piece positions.
- **BL-1102: Opening Book & ECO Classifier:**
  - Integrated offline opening tree database (e.g. Polyglot / JSON opening book).
  - Real-time ECO code and opening name identification (e.g., "B90 Sicilian Defense, Najdorf Variation").
- **BL-1103: PGN Multi-Variation Tree Navigation:**
  - Full recursive branching tree support for alternative moves and annotations.

### 2.2 Engine & Analysis Capabilities

- **BL-1104: Stockfish Multi-PV (Multiple Principal Variations) Analysis:**
  - View top 3-5 candidate moves simultaneously with live evaluations.
- **BL-1105: Stockfish Hash Table & CPU Thread Customization:**
  - Settings UI allowing user to configure memory allocation (16 MB to 512 MB) and WebWorker thread concurrency.
- **BL-1106: Offline Game Blunder Analysis & Graph:**
  - Post-game automated review generating accuracy metrics, blunders, mistakes, and advantage graphs.

### 2.3 Presentation & User Experience Polish

- **BL-1107: Custom Piece Sets & SVG Importer:**
  - Additional piece sets (Staunton, Modern, Neo, Alpha) and custom vector piece pack loading.
- **BL-1108: Move Arrows & Right-Click Square Highlights:**
  - Interactive right-click drag move arrows (green, orange, red) and square highlight badges for analysis.
- **BL-1109: Blindfold & Coordinate Training Modes:**
  - Dedicated training modes for chessboard coordinate recognition and blindfold visualization.

### 2.4 Desktop & Platform Integration

- **BL-1110: Native Windows System Tray Quick-Play Menu:**
  - Minimize to system tray with quick-launch puzzle or daily challenge shortcuts.
- **BL-1111: Automated Update Notifications via Local Manifest:**
  - Optional local-first release check checking GitHub Releases metadata without telemetry.
