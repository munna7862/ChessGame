## 1. Overview & Test Objectives

The primary objective of Sprint 06 is to publish ChessForge v1.0.0, validate complete release deliverables, verify checksum integrity, execute smoke test scenarios on release bundles, ensure release notes and known issues accuracy, and establish a clear, isolated post-release engineering baseline and v1.1 backlog without altering v1.0 scope.

## 3. Automation Strategy & Quality Gate Thresholds

- **Unit & Integration Test Suite (`Vitest`):** Execute `src/test/releaseBaselineValidation.test.ts` to assert all release artifacts, checksum algorithms, release notes extractors, known issues, and version consistency.
- **End-to-End Test Suite (`Playwright`):** Complete human-vs-human and human-vs-computer game flows, clock expiration, PGN export, and FEN workflows.
- **Static Analysis & Linting:** 0 TypeScript compile errors (`tsc --noEmit`), 0 ESLint warnings (`eslint .`), and 100% Prettier compliance (`prettier --check .`).
- **Success Criteria:** 100% Pass rate across all suites, 0 skipped tests (`it.skip`/`test.skip` strictly prohibited).
